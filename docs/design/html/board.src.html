可实现性对照

本板即报告

这块设计板同时是一份可实现性报告

下面每一项都在本页真实生效 —— 浏览器做得到，Qt Widgets 不一定接得住。 这正是「HTML 设计板 → Qt 实现」的真正损耗点，也是路线 C 比 Figma 更"诚实"的地方： Figma 画得出 QSS 永远做不了的柔光，而落差要到几个月后才暴露；这里就地可见。

本页用到的能力浏览器 / 小程序Qt Widgets（QSS）
var(--color-*) 变量引用原生支持无原生变量 必须代入字面值，失去「改一处全变」
box-shadow 卡片柔光原生支持完全不支持 只能 QGraphicsDropShadowEffect，且一个控件仅能挂一个
transition 悬停过渡原生支持不支持 无过渡与缓动
CSS grid 2×2 节奏卡浏览器原生小程序仅 Flex无 CSS 布局 需 QGridLayout 手工排
line-height 行距松弛感原生支持无此属性 需 QTextDocument 或补 padding
letter-spacing 标题字距原生支持须走 API QFont.setLetterSpacing
内嵌品牌字体（data URI）本板即生效可达成 QFontDatabase.addApplicationFont（已在用）
线性渐变 Hero 底原生支持须走 API QSS/画刷渐变，非声明式

如何更新本板 —— 真源只有一个，改完重跑即可，不要手改本产物： 
# 1) 改 token 真源
#    app/ui/theme/tokens.py

# 2) 重跑导出（CSS / WXSS，给设计板与小程序）
.venv/Scripts/python.exe tools/export_css_tokens.py

# 3) 重新生成本设计板（注入 token + 内嵌品牌字体）
.venv/Scripts/python.exe tools/build_design_board.py

结构源在 docs/design/html/board.src.html；改动请改那里。 token 命名与 Figma 侧同源：color.bg.canvas → --color-bg-canvas。

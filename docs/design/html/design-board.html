这块设计板同时是一份可实现性报告

下面每一项都在本页真实生效——浏览器能做到，Qt Widgets 不一定接得住。这正是「HTML 设计板 → Qt 实现」的真正损耗点。

本页用到的能力浏览器 / 小程序Qt Widgets (QSS)
var(--color-*) 变量引用 原生支持 无原生变量 必须代入字面值
box-shadow 卡片柔光 原生支持 QSS 不支持 需 QGraphicsDropShadowEffect，且一个控件只能挂一个
transition 悬停过渡 原生支持 不支持 无 transition / easing
CSS grid 2×2 节奏卡 浏览器原生 / 小程序仅 Flex 无 CSS 布局 需 QGridLayout 手工排
line-height 行距松弛感 原生支持 QSS 无此项 需 QTextDocument 或手工 padding
letter-spacing 标题字距 原生支持 须走 API QFont.setLetterSpacing
